L'inférence de type, étape par étape.

Cet outil est un interpréteur pour une sous-partie du langage Haskell, qui permet de visualiser l'inférence de type étape par étape.

Utilisation

La REPL sert juste à afficher le résultat. Pour utiliser l'interpréteur, il faut créer un nouveau fichier, à l'aide de l'icône dossier, en haut à gauche.

Les trois boutons en haut à droite servent respectivement à :

  • lancer l'inférence de type étape par étape
  • exécuter le code (fait automatiquement à la fin de l'inférence de type)
  • arrêter l'inférence ou l'exécution

Voici quelques exemples de code qui peuvent être utilisés : 

main = print "Hello World!"
len []    = 0
len (_:b) = 1 + (len b)

main = print (len [1,2,3])
myMap f [] = []
myMap f (a:b) = (f a) : (myMap f b)

main = print(myMap (\x -> x * x + 1) [3,4,5])
Spécifications

Seulement une sous-partie de Haskell est couverte par l'interpréteur. De plus, très peu de primitives ont été implémentées.

Même s'il serait intéressant d'utiliser cet outil à des fins pédagogiques en classe, c'est avant tout (et pour l'instant) a proof of concept.

Cette version de Haskell n'implémente pas l'évaluation paresseuse.Résumé simplement, l'interpréteur accepte des programmes Haskell qui n'utilisent pas :

  • les where
  • la notation | (guards)
  • les list comprehensions
  • des monades autres que print
  • les type classes

Caveat

Il y a des bugs en tout genre à travers l'interpréteur...

Contexte

Ce projet est le résultat d'un travail de maîtrise en informatique à l'Université de Montréal, portant sur la visualisation de l'inférence de type étape par étape pour Haskell.

Le mémoire correspondant est disponible sur la page web de l'université : papyrus .

Le repository du projet est ici : Github .

Résumé du projet :

Pour prévenir de certaines erreurs au run-time, les langages statiquement typés vérifient qu'un programme est correctement typé. Pour ce faire, les types des expressions qui composent le programme sont inférés.

Le fonctionnement de cette inférence n'est pas évident à comprendre pour les débutants. L'outil conçu est un interpréteur Haskell (langage de programmation fonctionnel) qui permet d'avancer étape par étape à travers l'inférence de type, dans le but de mieux expliquer son fonctionnement.

Le mémoire explique tout le projet, son développement, sa motivation, son évaluation, ...

Ce projet est une extension de codeBoot , un interpréteur Python conçu à l'Université de Montréal, utilisé dans l'enseignement.

Vu que codeBoot n'est pas open source, seulement le code de l'interpréteur qui a été ajouté est disponible sur le repository du projet.

Type inference, step by step.

This tool is an interpreter for a subset of the Haskell language, which lets you visualize type inference step by step.

Usage

The REPL is only used to display the output. To use the interpreter, create a new file with the folder icon in the top left.

The three buttons at the top right are used, respectively, to:

  • start step-by-step type inference
  • run the code (done automatically at the end of type inference)
  • stop the inference or the execution

Here are a few code examples you can use: 

main = print "Hello World!"
len []    = 0
len (_:b) = 1 + (len b)

main = print (len [1,2,3])
myMap f [] = []
myMap f (a:b) = (f a) : (myMap f b)

main = print(myMap (\x -> x * x + 1) [3,4,5])
Specifications

Only a subset of Haskell is covered by the interpreter, and very few primitives have been implemented.

Although it would be interesting to use this tool for teaching in class, it is (for the time being) a proof of concept.

This version of haskell does not use lazy evaluation. In short, the interpreter accepts Haskell programs that do not use:

  • where clauses
  • the | notation (guards)
  • list comprehensions
  • monads other than print
  • type classes

Caveat

There are all sorts of bugs throughout the interpreter...

Background

This project is the result of a master's thesis in computer science at the Université de Montréal, on visualizing step-by-step type inference for Haskell.

The thesis is available on the university's website: papyrus .

The project repository is here: Github .

Project summary:

To prevent certain run-time errors, statically typed languages check that a program is well typed. To do so, the types of the expressions that make up the program are inferred.

How this inference works is not obvious to beginners. This tool is a Haskell interpreter (a functional programming language) that lets you step through type inference in order to better understand how it works.

The thesis covers the whole project: its development, motivation, evaluation, ...

This project is an extension of codeBoot , a Python interpreter designed at the Université de Montréal and used in teaching.

Since codeBoot is not open source, only the interpreter code that was added is available in the project repository.
